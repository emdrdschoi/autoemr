# v3.136 — 혈압상승제/젖산 마지막 입력 이동 수정

UO <200에서 혈압상승제 선택까지 Tab을 1회에서 2회로 수정했습니다. 이후 Tab 2회로 lactate에 입력합니다. 승압제 사용 기본값은 No이며, 승압제 용량이나 dobutamine 사용이 있으면 Yes로 선택합니다.

검증: 마지막 Tab 2회 → No(Down 2회) → Tab 2회 → Lactate 0.7 입력 순서를 모의 검사했습니다. 수치/취소/포커스 및 분리 GUI 검사 통과. 실제 EMR은 조작하지 않았습니다.

PC 업데이트만 필요하며 서버 재배포는 불필요합니다.

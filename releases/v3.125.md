# EMRauto v3.125

사전정보 전송에 시트 쓰기 권한이 있으면 PC에서 HxSubmit에 직접 저장합니다. 휴대폰 사전정보 목록을 갱신하거나 기존 문진 작업자가 실행되면 HxRequests에 반영합니다. 시트 미연결, 읽기 전용, 전송함 미설정 또는 응답 유실 시 같은 요청 ID로 웹앱 경로를 사용합니다. 문진 결과는 기존 텍스트 형식으로 입력합니다.

## 적용

1. 서버 ZIP의 Code.gs로 기존 정리기 1의 통합 스크립트를 갱신하고, 기존 웹앱 배포를 새 버전으로 업데이트합니다.
2. 같은 Apps Script 편집기에서 enableDirectHxWrites_ 함수를 한 번 실행합니다. HxSubmit 탭이 생성됩니다. 기존 일분 주기 resumeRowHx 트리거를 유지합니다.
3. PC를 v3.125로 업데이트하고 트레이의 Google Sheets 연결에서 한 번 다시 로그인해 쓰기 권한을 승인합니다. 해당 구글 계정에는 정리기 시트 편집 권한이 필요합니다. 재인증하지 않은 PC는 기존 웹앱으로 전송합니다.

질환·소아·외상 차트 그림을 같은 탐색 주기에 확인합니다. PC의 환자 DB와 설정은 패키지에 포함하지 않습니다.

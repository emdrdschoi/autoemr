# v3.116 — Sheets 로그인 Chrome 우선

Google Sheets 로그인 시 Chrome 설치 경로를 확인하여 Chrome 새 창으로 엽니다. Chrome이 없으면 Windows 기본 브라우저를 사용합니다. 사용자별/전체 설치 레지스트리와 일반적인 설치 경로를 확인하며 기본 브라우저 설정 자체는 변경하지 않습니다.

로그인 후 자동 반영과 기존 인증 방식은 유지합니다. PC만 업데이트하면 되고 서버 변경은 없습니다. 로그인 도우미 구문 및 오프라인 회귀검사로 확인했으며 실제 병원 PC 브라우저 로그인은 테스트하지 않았습니다.

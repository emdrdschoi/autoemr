# PC 3.123 — FENa 표시 수정

기존 텍스트 Hx 방식(PC 3.118 기반)으로 유지합니다. F4와 Ctrl+3의 짧은 요약에서도 FENa를 표시합니다. eGFR과 AKI 유무에 관계없이 검사 시간·검체·단위가 맞는 혈액/소변 Na·Cr 네 결과로 계산합니다. 시각이 없는 경과기록에서는 직접 보고된 FENa 퍼센트를 표시할 수 있습니다. 날짜만 있는 네 수치로 새 값을 추정하지 않습니다.

PC 앱만 업데이트하세요. Apps Script나 Android 업데이트는 필요하지 않습니다. 실제 EMR에서 실행하지 않고 합성 자료로 검사했습니다.

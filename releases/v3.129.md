# EMRauto v3.129

SOFA 추가정보에서 SBP/DBP를 받아 MAP을 계산하고, Dopa·Epi·NE 용량과 단위를 직접 입력합니다. Dopa는 µg/kg/min, Epi·NE는 µg/min이 기본값이며 각 단위를 변경할 수 있습니다. µg/min은 체중으로 환산하며 체중 공란은 60kg을 사용합니다. SOFA 승압제 점수는 약별 용량 구간의 최대값을 반영합니다.

Ctrl+3 또는 위젯 Lab 정리 후 ‘패혈증 서식지 입력’을 누르면 환자별 Lab 수치와 SOFA 추가정보를 확인·보충할 수 있습니다. 새 빈 서식을 확인한 뒤 시작하면 3초 후 GCS 3402,763에서 Tab 순서대로 해당 구간에 숫자를 입력합니다. Esc/창 변경 시 중단하며 자동 저장·서명하지 않습니다. 서식에는 환산 설명 없이 숫자만 들어갑니다.

실제 EMR은 실행하지 않고 경계값, 결측값, 단위 환산, 취소·창 전환, 키입력 모의 테스트 및 독립 GUI 배치를 검사했습니다. 첫 사용 시 병원 서식의 Tab 순서와 입력 구간을 확인해주세요. 수정·재실행은 새 빈 서식에서 시작합니다.

PC 전용 업데이트입니다. 서버 ZIP은 v3.128과 동일하며 재배포할 필요가 없습니다. Android 변경 없음. 사용자 DB·설정·인증파일은 패키지에 포함되지 않습니다.

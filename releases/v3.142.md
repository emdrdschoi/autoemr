# v3.142 — FiO2 산소 유량 입력

SOFA FiO2/L 입력에서 0.21·21·21%는 21%, 숫자 1은 100%로 해석합니다. 숫자 2~15 또는 L/l 표기(1L 포함)는 사용자 지정식 0.21 + L×0.04로 환산합니다. 2L=0.29, 15L=0.81입니다.

유량 환산값은 SOFA 근거에 환산 추정으로 표시하며 패혈증 서식 P/F에도 적용합니다. 잘못된 문자열과 범위 밖 값은 계산에서 제외합니다. 접힌 SOFA 제외 규칙은 유지합니다.

검증: 단위/경계값, 입력 연결, 기존 Lab 분리 검사 및 GUI 검사 통과. 실제 EMR은 실행하지 않았습니다.

PC만 업데이트하면 됩니다. 서버 재배포는 불필요합니다.

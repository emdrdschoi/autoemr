# v3.112 — 위젯 하단 간소화

- 관리자/DB/시트를 단축키 안내 아래 한 줄로 이동하고 고정 이름의 색으로만 상태를 표시합니다. DB 및 시트 클릭 기능은 유지합니다.
- 하단 안내에서 F1/F3를 빼고 C+1 lab저장, C+2 부분저장, C+3 lab정리, F4 변환, C+4 약조회, C+5 약조회(상세), C+Q 재시작을 표시합니다. 사용자 지정 단축키가 있으면 해당 키로 표시합니다. F1/F3 기능 자체는 유지됩니다.
- ‘새 환자는 새 접수 · 기존 수정은 별도 버튼’ 고정 안내와 별도 상태 줄을 없앴습니다. 전송 알림은 기존 상태 줄을 사용하며 구체적인 오류는 덮어쓰지 않습니다.

PC만 업데이트하면 됩니다. 서버 파일은 v3.110과 동일합니다. 전체 오프라인 회귀검사로 확인했으며 실제 EMR은 조작하지 않았습니다.

# Android 0.1.5 — 프롬프트 캐시

APK와 서버 지원 ZIP의 Code.gs를 업데이트하고 기존 URL로 새 버전 배포하세요. Editor.html/PC는 변경 없습니다.

목록 새로고침에서 config!B2를 앱에 암호화 저장합니다. 이후 준비 요청은 저장된 프롬프트를 재사용하여 B2 읽기를 생략합니다. 캐시 누락/손상은 서버 조회로 복구합니다. URL·시트별로 분리하고 이미 준비된 기록의 재시도는 기존 prompt를 유지합니다.

B2를 바꿨다면 앱에서 목록 새로고침을 눌러야 반영됩니다. 자동 변경 감지는 아닙니다. 환자 매칭·기록 저장 서버 요청은 남으므로 서버 지연 전체가 없어지지는 않습니다. 대화·전사·추가 메모는 기존처럼 Gemini에 포함됩니다.

합성 서버 테스트로 캐시 사용 시 config 조회 0회, 재시도 snapshot 유지, 오류 후 웹앱 격리를 검증했습니다. APK 컴파일/서명 및 오프라인 검증 완료. 실제 휴대폰 지연 개선량과 원격 배포는 미검증입니다.

# v3.131 — 한 번 클릭으로 업데이트

트레이에서 앱 업데이트 확인을 누르면 새 버전을 확인하고 다운로드, 적용, 재시작까지 이어집니다. 별도의 다운로드 클릭이나 재시작 확인은 필요 없습니다.

진행 중인 입력/전송/수정, 미전송 내용이 있으면 적용을 멈추고 이유를 표시합니다. 작업을 마친 뒤 업데이트 메뉴를 다시 누르면 준비한 업데이트를 적용합니다. 앱 시작 시 자동 확인은 알림만 유지합니다.

PC만 업데이트하면 됩니다. 서버는 v3.128과 동일하며 재배포가 필요 없습니다.

검증: 모의 업데이트 흐름, 작업 중 차단, 파일 교체/롤백 검사 통과. 실제 EMR을 실행하지 않았습니다.

사전정보 목록 정렬 후 선택 대상이 달라질 수 있던 문제와 관리 화면의 응답 지연 처리를 수정했습니다.

- 미리보기·수정·삭제·결과 복사·EMR 입력이 동일한 고유 ID를 사용합니다.
- 선택 해제 시 이전 미리보기를 지우고, 삭제 확인창에는 실제 대상 내용을 표시합니다.
- 수정창 조회에는 읽기 전용 대체 통신을 적용합니다. 저장·삭제는 자동 재전송하지 않습니다.
- 삭제 응답 미확인 시 목록을 다시 조회합니다.
- 서버 상세 조회는 ID를 확인한 단일 행을 우선 읽습니다.

## 설치

- **PC:** `EMRauto_v3.99_compact.zip`을 내려받아 실행 중인 앱을 종료하고 기존 폴더에 덮어씁니다. 기존 db/INI/auth/클릭 매핑은 유지하세요.
- **서버:** `Historytaker_v3.99_server.zip`의 통합 Code.gs를 기존 Apps Script 프로젝트에 교체하고 기존 웹앱 배포를 새 버전으로 업데이트합니다. Editor.html은 v3.98과 동일합니다. 자세한 절차는 ZIP의 V3_99_DEPLOY.md를 참고하세요.
- 시트 데이터나 DB를 초기화하지 마세요.
- SHA256SUMS.txt는 첨부 ZIP의 SHA256 체크섬입니다.

전체 오프라인 회귀검사를 통과했습니다. 실제 EMR 입력과 원격 Apps Script 배포는 수행하지 않았습니다.

현재 v3.99에는 앱 자동 업데이트 기능이 포함되지 않았습니다.

# v3.114 — F3를 클립보드 Hx 입력으로 변경

- F3는 기존 Ctrl+F3의 검증된 클립보드 Hx 입력으로 동작합니다. 서버를 조회하지 않습니다.
- 기존 기본 설정(F3 조회 / Ctrl+F3 클립보드 입력)은 새 기본값으로 전환합니다. 별도로 지정한 사용자 단축키는 유지합니다.
- 위젯 Hx 입력 버튼은 기존 결과 조회/입력 동작을 유지하고 [F3] 표시는 제거했습니다. 사전정보 선택과 자동입력 대기도 유지됩니다.
- Ctrl+3 저장 Lab 정리는 변경하지 않았습니다. F3 클립보드 입력의 필수 섹션 검사·입력 중복 방지·CRLF 처리는 유지합니다.

PC만 업데이트하면 됩니다. 서버는 v3.110과 동일합니다. 오프라인 회귀검사로 확인했으며 실제 EMR 입력은 테스트하지 않았습니다.

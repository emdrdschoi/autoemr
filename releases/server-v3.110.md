# 웹 입력기 v3.110 — 기존 기록을 유지하면서 사전정보 재사용

- 이미 연결된 사전정보도 [재사용]으로 목록에 표시합니다.
- 선택한 사전정보를 새 문진에 복사하여 별도 기록으로 정리합니다. 원래 문진의 연결·결과는 변경하지 않습니다.
- 다른 문진이 정리 중이어도 같은 사전정보를 새 문진에 사용할 수 있습니다. 새 결과는 PC 목록이나 최신 결과로 불러옵니다.
- DB 관리의 미연결 목록에는 실제 미연결 항목만 표시합니다. 삭제된 항목과 오래된 수정 충돌에 대한 보호는 유지합니다.

적용: ZIP의 Code.gs와 Editor.html을 기존 Apps Script에 교체한 뒤 기존 배포를 새 버전으로 업데이트하세요. PC 업데이트는 필요 없습니다(PC 최신 v3.109). 클릭 좌표 변경 없음.

모의 서버·브라우저 검사에서 기존 결과 보존, 별도 결과 생성, 중복 저장 방지, 동시 진행을 확인했습니다. 실제 EMR 입력 및 원격 Apps Script 배포는 수행하지 않았습니다.

# HXJSON1 구조화 기록 — PC 3.119 / Android 0.1.22

Gemini가 JSON Schema에 맞춰 병력/진찰/태그를 반환하고, 시트에는 JSON 그대로 저장합니다. PC가 기존 EMR 텍스트로 변환하므로 모델의 구분선·제목·괄호 실수를 줄입니다. 기존 텍스트도 계속 지원합니다. 클릭 좌표는 변경하지 않았습니다.

**적용 순서: PC 3.119 → Code.gs 교체 및 기존 웹앱 새 버전 배포 → Android 0.1.22 → PROMPT_JSON_V1.txt를 config!B2에 값으로 붙여넣기 → 앱 설정에서 프롬프트 수동 가져오기·저장.** Editor.html 변경 없음. 기존 작업은 고정된 프롬프트를 유지하므로 새 형식을 적용하려면 전사 재사용으로 새 기록을 만드세요.

프롬프트 중복/충돌을 정리하고, 미시행 진찰의 정상 처리나 근거 없는 통증 간격/정확한 onset 시각 추정을 제거했습니다. 기존 임상 작성 규칙과 EMR 선택지는 보존했습니다.

검증: 합성 JSON 공통 fixture, 서버 저장/재시도, Android 오프라인 검사, 격리 PC 회귀검사, 빌드/서명. 실제 휴대폰·유료 Gemini·운영 DB·EMR 입력은 미검증. 원격 Apps Script 배포는 사용자가 해야 합니다.

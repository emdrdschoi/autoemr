# EMRauto v3.128

PC 위젯은 시작 약 3초 뒤 DB와 시트 연결을 확인합니다. 각 연결이 성공하면 5분 뒤, 실패하거나 미연결이면 1분 뒤 다시 확인합니다. 시트 로그인 정보가 바뀌거나 DB 표시를 누르면 바로 확인합니다. 환자 입력대기와 사전정보 전송은 기존대로 동작합니다.

Gemini 호출은 Android 앱에서만 수행합니다. PC와 웹 편집기는 내용 저장과 결과 조회를 지원합니다. 웹 편집기의 완료·재시도와 PC의 저장 후 재정리는 제공하지 않습니다. Google Form 제출은 대화 원문만 보관합니다. 전환 전에 서버 정리 대기였던 기록은 원문을 보존하고 ANDROID_ONLY 상태로 표시합니다. 이 기록이 Android로 자동 전송되지는 않습니다.

서버의 1분 주기 resumeRowHx 트리거를 유지하세요. 전환 시 한 번 기존 결과를 점검하고 이후에는 직접 전송함을 확인하여 사전정보를 접수합니다. 모델 호출은 하지 않습니다. Android에서 완료한 결과는 기존 PC에서도 조회할 수 있습니다.

적용하려면 정리기 1 Apps Script의 기존 통합 코드와 Editor.html을 이 버전의 Code.gs 및 Editor.html로 교체하고 기존 웹앱 배포를 새 버전으로 업데이트하세요. 실행 중인 기존 웹 정리는 먼저 마친 뒤 교체하세요. PC 트레이에서 앱 업데이트 확인을 누르세요. 기존 Android 앱을 계속 사용할 수 있습니다.

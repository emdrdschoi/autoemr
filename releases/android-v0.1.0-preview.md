# Android 음성기록 0.1.0 미리보기

사용자 API 키로 OpenAI Whisper → Gemini를 휴대폰에서 직접 호출합니다. 별도 서버 설치 없이 기존 Apps Script/Sheets/PC Hx 입력과 연결합니다.

- 녹음은 기기에 저장하고, 전송 확인 후 즉시 다음 환자의 새 녹음 화면을 엽니다.
- 녹음과 처리 서비스를 분리했습니다. 이전 환자 처리 중 다음 환자 녹음이 가능합니다.
- 사전정보 새로고침/선택, 직접 입력, 사전정보 없이 전송을 지원합니다.
- 환자별 진행상황·결과·녹음 재생·단계별 재시도·기기 기록 삭제를 제공합니다.
- API 키/텍스트/작업 상태는 Keystore 기반 암호화 저장, WAV는 앱 비공개 저장소에 보관합니다.
- 서버 저장은 기존 ID/DB epoch/사전정보 재사용 규칙을 유지하고, 응답 유실 재시도 시 기록을 중복 생성하지 않습니다. 기존 서버의 Gemini 키를 사용하지 않습니다.

## 설치

1. `Historytaker_android_0.1.0.zip`의 Code.gs로 기존 통합 Apps Script를 교체하고 **기존 배포를 새 버전으로 갱신**하세요. URL, 접속 코드, prompt B2, 기존 트리거는 유지합니다. Editor.html은 변경되지 않았습니다.
2. `EMRVoice-0.1.0-preview.apk`를 Android 8.0 이상 기기에 설치합니다.
3. 설정에 본인 OpenAI/Gemini API 키와 기존 웹앱 접속 코드를 입력합니다.

PC 업데이트는 필요 없습니다. 이 Android prerelease는 Windows 자동 업데이트의 최신 버전을 바꾸지 않습니다. 상세 설치·저장 정책은 첨부 INSTALL.md를 참고하세요.

## 검증 범위

APK 컴파일/서명 검증, 실제 처리 파이프라인의 음성 조각/Gemini/저장 실패 복구와 환자 분리, 합성 시트의 매칭/중복 저장/상태 복구 테스트, 기존 오프라인 회귀 검사를 통과했습니다.

**개발 서명한 미리보기입니다. 실제 Android 기기의 녹음·화면 꺼짐·전화 중단과 실계정 AI 호출은 아직 시험하지 않았습니다.** 첫 사용은 가상 사례로 확인하세요. Apps Script 원격 배포는 자동으로 수행하지 않았습니다. 앱을 강제 종료한 뒤에는 다시 열어 중단 작업을 재시도해야 합니다.

# v3.113 — 위젯 경고 수정과 Google 로그인 자동 반영

v3.112에서 별도 안내 줄을 제거한 뒤 대기환자 수정 경로에 남아 있던 hxSubmissionText 참조를 기존 hxStatusText로 교체했습니다. 제거한 변수 참조를 확인했고, 모의 위젯 검사에 실제 HxEditWaiting 진입 경로를 추가했습니다.

Google 로그인 후 ‘재시작 후 F3’ 안내를 제거했습니다. 앱은 인증파일 변경을 감지해 이전 토큰 캐시와 Sheets 실패 대기시간을 갱신하고, 유휴 상태에서 연결 상태를 확인합니다. 강제 재시작이나 자동 F3 입력은 하지 않으므로 작성 내용과 대기를 유지합니다.

PC만 업데이트하면 됩니다. 서버는 v3.110과 동일하며 재배포할 필요가 없습니다. 전체 오프라인 검사로 검증하고 실제 EMR은 실행하지 않았습니다.

# v3.134 — 서식 숫자 표기 및 RR 입력

패혈증 서식 미리보기와 전송 문자열에서 부동소수점 꼬리를 제거합니다. T.b 0.55, Cr 3.18, Lactate 0.7 형태로 입력하며 계산 MAP는 소수 첫째 자리, P/F는 둘째 자리까지 표시합니다.

SOFA 추가정보에 RR 입력칸을 추가하여 패혈증 서식 qSOFA RR에 연결합니다. 접기/펼치기 시 값 유지 및 지움 동작을 지원합니다.

Lactate 값이 미리보기에 있는 경우 마지막 입력 명령까지 전달하는 것을 모의 검사했습니다. 실제 EMR 마지막 칸 도달은 현장에서 확인이 필요하며 기존 Tab 횟수는 변경하지 않았습니다.

검증: 소수점/작은 용량/0 값, RR 연결, 모의 입력/취소, 분리 GUI 검사 통과. PC 업데이트만 필요하며 서버 재배포는 불필요합니다.

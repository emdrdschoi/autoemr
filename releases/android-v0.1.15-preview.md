# Android 0.1.15 — 실패 단계 자동 재시도

일시적인 연결 오류/시간 초과와 HTTP 408/429/500/502/503/504에서 작업당 최대 3회(5초·15초·45초 후) 자동 재시도합니다. 저장된 전사·prompt·결과를 재사용하며 시트 저장만 실패했으면 AI를 재호출하지 않습니다. 대기 중 다른 준비된 작업을 진행하고 진행 목록·알림에 횟수를 표시합니다.

인증/설정/환자 연결 충돌/모델 결과 형식/파일 오류는 멈춰 표시합니다. 한도 소진 후 수동 재시도 가능. 앱·OS가 서비스를 종료한 경우에는 기존처럼 수동 재개합니다.

AI 응답 수신 전에 통신이 끊겼다면 재호출 시 추가 API 비용이 발생할 수 있습니다. APK만 업데이트하세요. 서버/PC 변경 없음. 합성 재시도·단계 보존 검사 및 APK 컴파일·서명 검증 완료. 실제 휴대폰 네트워크 장애 상황은 미검증입니다.

# Android 0.1.8 — 사전정보 결정 순서에 따른 완료·전송

APK만 업데이트합니다. 서버는 0.1.5 이상 기준이며 이번 서버 변경은 없습니다.

- 01 녹음·대화 / 02 사전정보·확인·전송 / 03 보관함·설정.
- 미선택과 명시적 사전정보 없이 진행을 구분합니다.
- 사전정보를 먼저 결정하면 완료·전송 버튼으로 녹음 종료 후 자동 접수. 20분 이상은 확인창 유지.
- 녹음을 먼저 완료하면 02로 이동하며, 이후 사전정보 결정 후 전송 버튼을 사용합니다.
- 앱 시작·새 기록에서 최근 10분 이내 갱신된 최신 미연결 사전정보 자동 연결. 다른 로컬 기록이 사용한 항목 제외. 직접 입력/선택과 녹음 완료 후에는 늦은 응답이 덮어쓰지 않습니다.
- 01 입력 있음 / 02 결정됨은 흰색에서 연한 초록색 카드로 표시합니다.

합성 상태·후보 선택·기존 파이프라인 회귀 검사와 APK 컴파일·서명 검증 완료. 실제 휴대폰 동작은 미검증입니다.

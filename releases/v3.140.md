# v3.140 — FENa pending 및 이전 전환 메뉴 제거

소변 Na/Cr 또는 해당 패널이 예약·진행 중이고 필요한 결과가 비어 있으면 FENa pending으로 표시합니다. 날짜 없는 예약도 포함하며 취소/완료된 검사는 제외합니다. 같은 검사의 완료 결과는 이전 pending을 해제합니다. 단기/장기 출력과 renal dysfunction 근거에 적용합니다.

트레이의 이전 설정 메뉴인 행 기반 전환을 제거했습니다. 현재 저장/문진 매칭 기능은 유지합니다. 계산 항목 제목에 남아 있던 5시간 제한 문구도 제거했습니다.

검증: 합성 예약/진행/취소/완료 및 날짜 없는 예약 보존을 포함한 478개 분리 AHK 검사 통과. 실제 EMR은 조작하지 않았습니다.

PC만 업데이트하면 됩니다. 서버 재배포는 불필요합니다.

# v3.109 — 사전정보 전송 순번 복구와 직접 입력 완료

- PC 전송 순번이 서버보다 뒤처졌을 때 거절 응답의 서버/기기/요청 정보를 검증하여 다음 전송 순번을 복구합니다. 기존 요청을 자동 재전송하지 않으며, 입력 내용을 확인한 후 사전정보 전송 버튼을 다시 누르면 새 요청으로 보냅니다.
- 거절된 요청을 하단에 ‘접수 완료’로 잘못 표시하던 문제를 수정했습니다.
- 웹에서 사전정보를 직접 입력했다면 완료 시 연결 선택창을 생략하고 작성한 내용으로 정리합니다. 사전정보가 공란이면 기존 연결 확인 과정을 유지합니다.
- PC ZIP과 서버 ZIP을 함께 적용해야 순번 복구가 동작합니다. 서버의 Code.gs와 Editor.html을 교체하고 기존 웹앱 배포를 새 버전으로 업데이트하세요. 접속 코드·트리거·시트 데이터는 유지합니다.

검증: 모의 AHK/Apps Script/브라우저 회귀검사. 실제 EMR 자동입력이나 실제 환자 데이터 생성은 테스트하지 않았습니다.

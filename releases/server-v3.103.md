웹앱에서 접속 코드 입력과 DB 조회보다 먼저 진료 대화를 입력할 수 있도록 변경했습니다.

- 웹앱을 열면 대화 입력칸부터 표시됩니다. 기억된 접속 코드가 있으면 백그라운드에서 연결합니다.
- 인증 성공/실패와 목록 응답이 작성 중인 대화를 지우지 않습니다.
- 기존 사전정보는 연결 후 직접 선택해 미리 붙일 수 있습니다. 대화는 유지됩니다.
- 연결 없이 완료하면 기존의 초안 저장 → 최신 사전정보 확인 → 정리 흐름을 사용합니다.
- 새 기록도 입력칸을 먼저 열고 목록을 백그라운드에서 갱신합니다.
- 저장/정리는 인증 후에만 실행하며 임상 내용을 localStorage에 저장하지 않습니다.

## 적용

기존 Apps Script 프로젝트의 **Editor.html**을 교체하고 기존 웹앱 배포를 새 버전으로 업데이트하세요. Code.gs는 v3.102 패키지와 동일합니다. PC 앱은 v3.102 그대로 사용합니다.

이 릴리스는 서버 전용이며 PC 앱 최신 릴리스/자동 업데이트 대상을 변경하지 않습니다.
인증·목록 지연과 실패를 포함한 모의 브라우저 및 서버 회귀검사를 통과했습니다. 실제 서버 배포와 Gemini 실행은 수행하지 않았습니다.

# v3.111 — 연결 상태 표시와 전송 버튼 구분

- 위젯에 관리자 실행, 웹앱 DB 연결, 선택 사항인 Google Sheets 연결 상태를 표시합니다.
- DB/시트 초록색은 실제 읽기 확인, 회색은 미연결·미확인, 빨간색은 확인 실패입니다. 저장된 인증파일만으로 연결 성공을 표시하지 않습니다.
- 시작 후 및 유휴 상태에서 1분마다 작은 읽기 요청으로 확인합니다. 전송/자동입력 대기/실행 중에는 검사를 건너뛰며, 확인이 오래되면 미확인으로 바뀝니다. DB 표시 클릭으로 접속 코드 입력/재확인, 시트 표시 클릭으로 기존 Google 연결 화면을 엽니다.
- 평소 버튼: ‘전송 → 입력대기’ / ‘전송’. 대기 중: ‘대기환자 수정’ / ‘새환자 전송’. 전송만 선택하면 결과를 기다리거나 EMR 입력을 시작하지 않습니다. 새환자 전송은 기존 환자 대기를 유지합니다.
- 클릭 좌표/PNG는 변경하지 않았습니다. 관리자 표시만 추가하며 자동 권한 상승은 하지 않습니다. 병원 PC에서는 자동실행.bat로 실행하세요.

PC 업데이트만 필요합니다. 동봉 서버는 v3.110과 동일합니다. 이전 서버를 사용하는 경우에만 기존 서버 안내에 따라 Code.gs와 Editor.html을 적용하세요.

검증: 분리된 모의 GUI/네트워크 상태 검사 및 전체 오프라인 회귀검사. 실제 EMR 입력은 실행하지 않았습니다.

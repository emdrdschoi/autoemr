# Android 0.1.14 — 다른 기기로 설정 이동

설정 화면에 암호화 파일 내보내기/가져오기를 추가했습니다.

1. 기존 기기: 설정을 저장한 뒤 내보내기 → 8자 이상 파일 비밀번호 설정 → 파일 저장.
2. Quick Share 등으로 .emrsettings 파일을 새 기기로 이동.
3. 새 기기: 설정 파일 가져오기 → 비밀번호 → 설정 교체 확인.

OpenAI/Gemini 키, 웹앱 접속 코드·주소·시트 ID·모델만 포함하며 녹음·환자 기록은 제외합니다. AES-256-GCM, PBKDF2-HMAC-SHA256 210000회, 임의 salt/IV. 비밀번호는 저장하지 않습니다. 녹음·처리 중 설정 교체 차단. 저장된 설정만 내보냅니다.

APK만 업데이트하세요. 합성 키로 왕복 복원·포함 필드 제한·틀린 비밀번호·변조 거부와 빌드·서명을 검증했습니다. 실제 두 기기간 파일 이동은 미검증입니다. 서버 변경 없습니다.

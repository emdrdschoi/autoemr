# v3.138 — SOFA 펼침 상태 적용 및 F4 서식 연결

SOFA 추가정보가 펼쳐져 있을 때만 수동 입력값을 사용합니다. 접혀 있으면 Ctrl+3/F4/위젯 Lab 정리 모두 SOFA를 표시하지 않으며 기존 입력값은 보관합니다.

F4로 정리한 원시 Lab/경과표도 패혈증 서식에 연결합니다. 이전 환자의 스냅샷은 F4 시작 시 비우고, 성공한 이번 검사값으로 교체합니다. 환자번호를 추정하지 않고 출처를 클립보드(F4)로 표시하며 저장 DB의 기간 필터는 적용하지 않습니다.

검증: 합성 F4 값 교체, 접힘 시 계산 제외/값 보존, 모의 서식 입력 및 분리 GUI 검사. 실제 EMR은 실행하지 않았습니다.

PC만 업데이트하면 됩니다. 서버 재배포는 불필요합니다.

# Android 0.1.20 — 수동 프롬프트 관리

설정에서 시트 config!B2 프롬프트를 직접 가져오고 앱에서 편집·저장할 수 있습니다. 목록 조회 때 로컬 프롬프트를 갱신하지 않습니다. 전송 시 내용을 기록별로 고정하며 재시도는 고정된 내용을 유지합니다.

- 설정 → 프롬프트 가져오기 · 수정 → 시트에서 가져오기 또는 직접 편집 → 앱에 저장
- 기존 암호화 캐시 유지. 시트 원본은 수정하지 않습니다.
- 프롬프트가 없으면 전송 전에 설정 안내. 묵시적인 시트 프롬프트 대체 없음.
- **APK + 지원 ZIP의 Code.gs 업데이트 필요**: 기존 Apps Script 배포를 새 버전으로 배포하세요. 목록에서 B2 읽기를 생략하려면 서버 mobile-0.1.20이 필요합니다. Editor.html/PC 변경 없음.
- Gemini Explicit Caching은 이번 버전에 활성화하지 않았습니다.

검증: Android 오프라인 회귀검사, 합성 서버 검사, APK 빌드·서명 검증. 실제 휴대폰 UI/유료 API/운영 시트 호출은 수행하지 않았습니다.

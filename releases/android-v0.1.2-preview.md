# Android 음성기록 0.1.2 미리보기

- 회청색 배경, 테두리 있는 구역/입력칸, 녹음·사전정보·전송·보관함 구분.
- 저장된 사전정보 즉시 선택과 목록 새로고침을 분리. 사전정보 없음 선택은 통신 없이 가능. 초기 목록이 없을 때도 전송 접수 후 백그라운드에서 연결 정보를 확인.
- 날짜별 녹음/전사 보관함: 원본 듣기/내보내기, 녹음으로 새 기록, 전사로 새 기록. 원래 기록은 유지하고 새 UUID로 사전정보를 다시 연결. 전사 재사용 시 Whisper 호출 생략.
- 현재 기록과 전송 확인에 입력 시간·녹음 길이·텍스트 길이 표시.
- 실시간 마이크 음량 그래프. 음성 인식 신뢰도가 아닌 입력 음량 표시입니다.
- 긴 무음 줄이기: 기본 켜짐, 전송 전 끌 수 있음. -55dBFS 이하 RMS가 3초 이상 이어질 때 양끝 0.5초씩 남김. 원본은 그대로 보관하고 전송 복사본만 처리. 작은 목소리와 무음을 완벽히 구분하지 않으므로 작은 목소리 문진은 끄세요.
- 앱 내 GitHub 업데이트 확인 → 최신 Android APK 다운로드. 브라우저에서 받은 APK는 사용자가 설치하며 기존 Android 서명 검증을 따릅니다. 자동 교체/강제 종료하지 않습니다.

0.1.0/0.1.1 사용자는 APK만 덮어 설치하세요. 기존 웹앱/서버/PC 코드는 변경되지 않았습니다. Windows 자동 업데이트 최신 버전도 유지합니다.

컴파일/서명, 단계별 복구, 전사 재사용·Whisper 생략, 무음 처리의 원본 보존·음성/짧은 공백 보존, WAV 연속성, 업데이트 버전 비교 검사를 통과했습니다. 실제 휴대폰 UI·오디오·배터리 정책은 아직 검증하지 않은 개발 서명 미리보기입니다.

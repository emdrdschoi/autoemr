# Android 0.1.11 — 녹음 버리기 / 다른 환자

녹음 화면에 두 버튼을 추가했습니다. 녹음 중·일시정지 상태에서도 사용 가능합니다.

- 녹음 버리기: 확인 → 녹음 종료 확인 → 현재 음성 전체 삭제. 사전정보·메모 유지. 녹음 시작으로 다시 녹음합니다.
- 다른 환자·새 기록: 확인 → 현재 녹음 전송 없이 보관 → 사전정보 미선택의 새 기록. 이 경로는 자동 사전정보 연결을 하지 않습니다.

두 동작은 자동 전송하지 않습니다. 녹음 종료 미확인 시 삭제/전환 중단. 처리 중·전사 완료된 음성은 녹음 버리기 대상에서 제외합니다.

APK만 업데이트(서버 0.1.5 이상 기준). 컴파일·서명 검증 완료. 실제 휴대폰 녹음 중단/파일 삭제 동작은 미검증입니다.

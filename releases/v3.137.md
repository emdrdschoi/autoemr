# v3.137 — 혈압상승제 No 직접 선택

No 선택은 End 키로 마지막 항목을 직접 선택하고 200ms 기다린 뒤 다음 필드로 이동합니다. 반복 Down 입력 중 Yes에 머문 채 다음 칸으로 이동할 가능성을 줄였습니다. Yes는 Home 후 Down 1회로 선택합니다. Tab 간격은 90ms에서 50ms, 항목 처리 후 간격은 100ms에서 50ms로 단축했습니다.

검증: 모의 입력에서 Tab 2회 → End(No) → Tab 2회 → lactate 입력을 확인했습니다. 실제 병원 EMR의 드롭다운 동작은 현장 확인이 필요합니다.

PC 업데이트만 필요하며 서버 재배포는 불필요합니다.
